## What you see

In the [`deep-nesting`](https://github.com/ciatlas/flowpact/tree/main/fixtures/deep-nesting) fixture:

```text
●  INFO  FP106 passthrough-dropped
  jobs.build passes "verbose" to .github/workflows/build.yml, which never reads it
  ▶ .github/workflows/pipeline.yml:25:7
```

## Why it matters

In deep call chains values are often forwarded level by level. When one level stops using an input, every caller above it keeps passing data that is silently dropped.

## How to fix

Stop passing the value here, or make the callee actually use (or forward) it.
