## Why it matters

Reusable workflow inputs are typed (`string`, `boolean`, `number`). Passing `"true"` (a string) to a boolean input fails the run when the call is evaluated, typically on a code path you did not test locally.

## How to fix

Pass a value of the declared type (unquoted `true`/`false` for booleans, an unquoted number for numbers).

## Example

<Tabs items={["Problem", "Fixed"]}>
<Tab value="Problem">

```yaml
with:
  dry-run: "true"   # declared type: boolean
```
