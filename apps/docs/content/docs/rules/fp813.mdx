## Why it matters

Without a declaration there is nothing to check against. The required impact is still useful when cutting a release.

## How to fix

Declare the impact: a Conventional Commits pull request title (`feat: …`, `fix!: …`), a `semver:*` label, or `--expect`.

## Configure

Change the severity (or turn the rule off) in `.github/flowpact/flowpact.config.yml`, by code or by name:

```yaml title=".github/flowpact/flowpact.config.yml"
rules:
  FP813: off
  # or: impact-undeclared: error
```

Explain it in the terminal:

```sh
flowpact explain FP813
```
