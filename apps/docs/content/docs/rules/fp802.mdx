## Why it matters

The contract is the reviewed record of what flows in and out. When it drifts silently, the next reviewer compares against stale information.

## How to fix

Run `flowpact generate` and commit the updated contracts. In CI, the flowpact action (check mode) attaches the regenerated contracts and a `git apply`-able patch to the run — see its job summary.

## Configure

Change the severity (or turn the rule off) in `.github/flowpact/flowpact.config.yml`, by code or by name:

```yaml title=".github/flowpact/flowpact.config.yml"
rules:
  FP802: off
  # or: contract-outdated: error
```
