## Why it matters

A mistyped workflow path or job id means the shape is silently ignored and the matrix stays unverified.

## How to fix

Use `<workflow path>#<job id>` exactly as in the repository (e.g. `.github/workflows/test.yml#test`), or remove the entry.

## Configure

Change the severity (or turn the rule off) in `.github/flowpact/flowpact.config.yml`, by code or by name:

```yaml title=".github/flowpact/flowpact.config.yml"

  FP405: off
  # or: unused-matrix-shape: error
```
