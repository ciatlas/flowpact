## Why it matters

GitHub limits how deeply reusable workflows can be nested and fails the run when the limit is exceeded. Deep chains are also where values get lost between levels.

## How to fix

Flatten the chain (call leaf workflows directly from a higher level). GitHub allows at most 10 levels; lower `limits.nestingDepth` to enforce a stricter internal limit.
