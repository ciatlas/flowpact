## What you see

In the [`cycles`](https://github.com/ciatlas/flowpact/tree/main/fixtures/cycles) fixture:

```text
✖  ERROR  FP608 undefined-needs-job
  jobs.report needs "linting", which is not a job in .github/workflows/main.yml (jobs: stage-b, missing, remote, report)
  ▶ .github/workflows/main.yml:12:22
```

## Why it matters

GitHub rejects the workflow when it is triggered.

## How to fix

Fix the job id or remove the dependency.

## Example

<Tabs items={["Problem", "Fixed"]}>
<Tab value="Problem">

```yaml
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - run: make
  deploy:
    needs: biuld   # no job "biuld"
    runs-on: ubuntu-latest
    steps:
      - run: make deploy
```

</Tab>
<Tab value="Fixed">

```yaml
  deploy:
    needs: build
```

</Tab>
</Tabs>
