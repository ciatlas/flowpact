## What you see

In the [`deep-nesting`](https://github.com/ciatlas/flowpact/tree/main/fixtures/deep-nesting) fixture:

```text
▲  WARN  FP304 step-output-never-written
  Step "sum" never writes output "sha" (it writes sha256) — did you mean "sha256"?
  ▶ .github/workflows/build.yml:22:21
```

## Why it matters

The read evaluates to an empty string. This is typically a typo in the `echo "name=value" >> $GITHUB_OUTPUT` line.

## How to fix

Write the output in the step (`echo "<name>=<value>" >> "$GITHUB_OUTPUT"`) or read the name it actually writes.

## Scope

Only scripts whose writes flowpact can name are judged. A step is skipped when its writes cannot be seen: `cat file >> "$GITHUB_OUTPUT"`, a computed name (`core.setOutput(name, …)`), or an `actions/github-script` script that loads a module (`require()`, `import()`; Node built-ins like `fs` aside), runs a program (`exec.exec()`), hands `core` to other code (`run({ core })`), or takes code from an expression (`script: ${{ inputs.code }}`). Words in strings, comments and template text do not count. Steps of other actions are not judged, since an action may set outputs of its own. Not reported in [generated files](/docs/configuration#generated-files), which are not edited by hand.

## Accept one finding

When a finding is intended, accept it with a reason rather than turning the rule off. It is listed apart from the other
findings, and does not fail the build.

**On its line**, with an [ignore comment](/docs/configuration#ignore-comments) alone on the line above it (the
editor's quick fix adds it there) or at the end of the line, after any other comment such as a version
(`# v4.3.0 # flowpact: ignore[FP304] why`):

```yaml title=".github/workflows/build.yml"
# flowpact: ignore[FP304] why it is acceptable here
checksum: ${{ steps.sum.outputs.sha }}
```

**In the config**, with an [override](/docs/configuration#overrides), which can expire:

```yaml title=".github/flowpact/flowpact.config.yml"
overrides:
  - rule: FP304
    target: ".github/workflows/build.yml#jobs.compile.steps.sum.outputs.sha"
    reason: Why it is acceptable here, at least 10 characters.
    expires: YYYY-MM-DD   # optional
```

`target` is the symbol the finding is about; to list them:

```sh
flowpact lint --format json | jq -r '.findings[] | select(.code == "FP304") | .symbol'
```
