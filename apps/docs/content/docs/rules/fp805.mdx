## Why it matters

An unreadable contract cannot be compared, so drift and breaking changes go unnoticed.

## How to fix

Contracts are generated: resolve the merge by running `flowpact generate` instead of editing the file.

## Configure

```yaml title=".github/flowpact/flowpact.config.yml"

  # or: contract-invalid: error
```
