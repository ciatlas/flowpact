| `FP104` | `unused-input` | Inputs | 🟡 warning |

## Why it matters

Dead inputs accumulate in large interfaces: callers keep computing and passing values that go nowhere, and readers assume a knob works when it does not.

## How to fix

Remove the input (and the callers’ bindings), or wire it to where it was meant to be used.

## Scope

Not reported in [generated files](/docs/configuration#generated-files), which are not edited by hand.

## Example

<Tabs items={["Problem", "Fixed"]}>

```yaml

  workflow_call:
    inputs:
      legacy-flag: { type: boolean }   # never referenced
```

</Tab>
<Tab value="Fixed">

```yaml

```
