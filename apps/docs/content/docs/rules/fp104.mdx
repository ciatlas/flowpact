## What you see

In the [`composite-actions`](https://github.com/ciatlas/flowpact/tree/main/fixtures/composite-actions) fixture:

```text
▲  WARN  FP104 unused-input
  Input "token" of .github/actions/install-tools is never read
  ▶ .github/actions/install-tools/action.yml:10:3
```

## Why it matters

Dead inputs accumulate in large interfaces: callers keep computing and passing values that go nowhere, and readers assume a knob works when it does not.

## How to fix

Remove the input (and the callers’ bindings), or wire it to where it was meant to be used.

## Example

<Tabs items={["Problem", "Fixed"]}>
<Tab value="Problem">

```yaml
on:
  workflow_call:
    inputs:
      legacy-flag: { type: boolean }   # never referenced
```

</Tab>
<Tab value="Fixed">

```yaml
# remove it, or use it:
if: inputs.legacy-flag
```

</Tab>
</Tabs>
