## Why it matters

GitHub rejects the call ("Invalid secret … is not defined in the referenced workflow").

## How to fix

Declare the secret under `on.workflow_call.secrets` in the callee, fix the name, or remove it.

## Example

<Tabs items={["Problem", "Fixed"]}>
<Tab value="Problem">

```yaml
jobs:
  deploy:
    uses: ./.github/workflows/deploy.yml   # declares the secret deploy-token
    secrets:
      deploy_token: ${{ secrets.DEPLOY_TOKEN }}
```

</Tab>
<Tab value="Fixed">

```yaml
    secrets:
      deploy-token: ${{ secrets.DEPLOY_TOKEN }}
```

</Tab>
</Tabs>
