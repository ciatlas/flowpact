| `FP502` | `expression-parse-error` | Env & expressions | 🔴 error |

## Why it matters

GitHub rejects the workflow when it is triggered, or fails the step that contains the expression.

## How to fix

Fix the syntax: strings use single quotes, `==` for equality, and every `$\{\{` needs a closing `\}\}`.

## Example

<Tabs items={["Problem", "Fixed"]}>
<Tab value="Problem">

```yaml

```
