## Why it matters

The `env` context only contains variables set by the workflow itself — not runner defaults like `GITHUB_SHA`. Reads of anything else evaluate to an empty string.

## How to fix

Define the variable under `env:`, write it to `$GITHUB_ENV` in an earlier step, or use the matching context (e.g. `github.sha`).

## Example

<Tabs items={["Problem", "Fixed"]}>
<Tab value="Problem">

```yaml
run: echo ${{ env.GITHUB_SHA }}
```

</Tab>
<Tab value="Fixed">

```yaml
run: echo ${{ github.sha }}   # or "$GITHUB_SHA" in the shell
```

</Tab>
</Tabs>
