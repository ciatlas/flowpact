## What you see

```text
●  INFO  FP403 dynamic-matrix-unverified
  jobs.dynamic has a runtime-computed matrix; reads of matrix.os, matrix.config cannot be verified
  ▶ .github/workflows/matrix.yml:17:7
```

## Why it matters

Dynamic matrices (`fromJSON(...)`) hide the same empty-value failure mode as static ones, but no tool can see it.

## How to fix

Declare the keys in the config (`matrixShapes: { "<workflow>#<job>": { keys: [os, config] } }`) so flowpact can verify reads, prefer a static matrix, or validate the generated JSON in the job that produces it.

## Example

<Tabs items={["Problem", "Fixed"]}>
<Tab value="Problem">

```yaml
jobs:
  test:
    needs: setup
    strategy:
      matrix: ${{ fromJSON(needs.setup.outputs.matrix) }}
    runs-on: ${{ matrix.os }}
```

</Tab>
<Tab value="Fixed">

```yaml
# .github/flowpact/flowpact.config.yml: the keys the generated matrix has
matrixShapes:
  .github/workflows/test.yml#test:
    keys: [os]
```

</Tab>
</Tabs>
