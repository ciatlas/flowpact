## What you see

In the [`ignore-comments`](https://github.com/ciatlas/flowpact/tree/main/fixtures/ignore-comments) fixture:

```text
▲  WARN  FP904 ignore-comment-invalid
  Ignore comment names an unknown rule "FP5O1" (did you mean FP501?)
  ▶ .github/workflows/release.yml:21:74
```

## Why it matters

Such a comment accepts nothing: the finding it was written for is still reported, and the comment hides why.

## How to fix

Correct the rule: its code or its name, as `flowpact rules` lists them, in brackets after `# flowpact: ignore`. The rules about overrides and ignore comments (FP9xx) check them once they are applied, so no comment can ignore them.

## Scope

Not reported in [generated files](/docs/configuration#generated-files), which are not edited by hand.

## Change the severity

Change the severity (or turn the rule off) in `.github/flowpact/flowpact.config.yml`, by code or by name:

```yaml title=".github/flowpact/flowpact.config.yml"
rules:
  FP904: off
  # or: ignore-comment-invalid: error
```

Explain it in the terminal:

```sh
flowpact explain FP904
```
