## Why it matters

GitHub rejects undeclared inputs to reusable workflows, and ignores them (with a warning in the log) for actions. Usually it is a typo or a leftover after an input was renamed, so the value you meant to pass never arrives.

## How to fix

Rename the key to the declared input, declare the input in the callee, or remove the stale binding.
