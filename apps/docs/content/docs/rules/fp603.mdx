## What you see

```text
●  INFO  FP603 remote-unverified
  jobs.remote calls remote workflow octo-org/shared/.github/workflows/lint.yml@v2; its interface is not verified
  ▶ .github/workflows/main.yml:10:11
```

## Why it matters

flowpact analyzes this repository only, so inputs, secrets and outputs of the remote workflow are taken on trust, unless `.github/flowpact/remotes.lock.yaml` records its interface.

## How to fix

Run `flowpact remotes update` to record its interface and have it checked, or nothing. If the workflow lives in this repository, set `repository: owner/repo` in the config so it resolves locally.
