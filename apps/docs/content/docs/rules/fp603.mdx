## What you see

In the [`cycles`](https://github.com/ciatlas/flowpact/tree/main/fixtures/cycles) fixture:

```text
●  INFO  FP603 remote-unverified
  jobs.remote calls remote workflow octo-org/shared/.github/workflows/lint.yml@v2; its interface is not verified
  ▶ .github/workflows/main.yml:10:11
```

## Why it matters

flowpact analyzes this repository only, so inputs, secrets and outputs of the remote workflow are taken on trust, unless `.github/flowpact/remotes.lock.yaml` records its interface.

## How to fix

Run `flowpact remotes update` to record its interface and have it checked, or nothing. If the workflow lives in this repository, set `repository: owner/repo` in the config so it resolves locally.

## Accept one finding

When a finding is intended, accept it with a reason rather than turning the rule off. It is listed apart from the other
findings, and does not fail the build.

**On its line**, with an [ignore comment](/docs/configuration#ignore-comments) alone on the line above it (the
editor's quick fix adds it there) or at the end of the line, after any other comment such as a version
(`# v4.3.0 # flowpact: ignore[FP603] why`):

```yaml title=".github/workflows/main.yml"
# flowpact: ignore[FP603] why it is acceptable here
uses: octo-org/shared/.github/workflows/lint.yml@v2
```

**In the config**, with an [override](/docs/configuration#overrides), which can expire:

```yaml title=".github/flowpact/flowpact.config.yml"
overrides:
  - rule: FP603
    target: "remote:octo-org/shared/.github/workflows/lint.yml@v2"
    reason: Why it is acceptable here, at least 10 characters.
    expires: YYYY-MM-DD   # optional
```

`target` is the symbol the finding is about; to list them:

```sh
flowpact lint --format json | jq -r '.findings[] | select(.code == "FP603") | .symbol'
```

`*` matches within a path segment and `**` across segments, so one entry accepts every finding whose symbol matches:
`target: '**#inputs.app-id'` is that input in every workflow and action.
