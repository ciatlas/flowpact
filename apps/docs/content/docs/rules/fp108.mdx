| `FP108` | `undefined-input-ref` | Inputs | 🔴 error |

## Why it matters

Undeclared inputs always evaluate to an empty value. This is usually a typo or a rename that missed a usage.

## How to fix

Fix the name, or declare the input under `on.workflow_call.inputs` / `on.workflow_dispatch.inputs` / `inputs:`.

## Example

<Tabs items={["Problem", "Fixed"]}>
<Tab value="Problem">

```yaml
run: ./build.sh ${{ inputs.tagret }}
```

</Tab>
<Tab value="Fixed">

```yaml
run: ./build.sh ${{ inputs.target }}
```

</Tab>
</Tabs>
