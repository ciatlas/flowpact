## Why it matters

A reference the lockfile lacks is not checked (unless `--fetch-remotes` or the action’s `remotes: fetch` fetches it for the run). It happens when a reference moves to another version, for example in a pull request from Renovate or Dependabot, until the lockfile is updated.

## How to fix

Run `flowpact remotes update` and commit the lockfile (see the Renovate and Dependabot recipes in the docs).
