## Why it matters

Only workflows with `workflow_call` can be called. GitHub rejects the caller ("is not a reusable workflow"), and none of the callee’s `workflow_dispatch` inputs count as a call interface.

## How to fix

Add `on: workflow_call:` (with the inputs, secrets and outputs the callers need) to the called workflow, or call the right file.

## Example

<Tabs items={["Problem", "Fixed"]}>
<Tab value="Problem">

```yaml
# deploy.yml
on:
  workflow_dispatch:
    inputs:
      target: { type: string, required: true }
```

</Tab>
<Tab value="Fixed">

```yaml
on:
  workflow_dispatch: ...
  workflow_call:
    inputs:
      target: { type: string, required: true }
```

</Tab>
</Tabs>
