## Why it matters

The call looks complete, so GitHub never complains about the required input, but when the outer caller omits the optional value the callee receives an empty string. The "required" guarantee is lost one level up.

## How to fix

Make the outer input required too, give it a default, or add a fallback: `${{ inputs.x || 'value' }}`.

## Example

<Tabs items={["Problem", "Fixed"]}>
<Tab value="Problem">

```yaml
# pipeline.yml
inputs:
  config: { type: string, required: false }
jobs:
  test:
    uses: ./.github/workflows/test.yml
    with:
      config: ${{ inputs.config }}   # test.yml: config is required
```

</Tab>
<Tab value="Fixed">

```yaml
inputs:
  config: { type: string, required: true }
```

</Tab>
</Tabs>
