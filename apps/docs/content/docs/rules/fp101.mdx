## Why it matters

For reusable workflows GitHub fails the run when a required input is missing — even if the input also has a `default`, which is then never used. For composite actions `required` is not enforced at all: the step silently runs with an empty string (or the default), which is how test variants get skipped unnoticed.

## How to fix

Pass the input under `with:`, or mark it `required: false` with a `default` if it is truly optional.

## Example

<Tabs items={["Problem", "Fixed"]}>
<Tab value="Problem">

```yaml
jobs:
  test:
    uses: ./.github/workflows/test.yml
    with:
      suite: unit
      # "config" is required by test.yml but not passed
```

</Tab>
<Tab value="Fixed">

```yaml
jobs:
  test:
    uses: ./.github/workflows/test.yml
    with:
      suite: unit
      config: release
```

</Tab>
</Tabs>
