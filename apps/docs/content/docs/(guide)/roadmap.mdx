## Shipped

### Lint

- **Data-flow engine:** workflows, local composite actions, nested reusable workflows and same-repository references,
  followed across files.
- **Exact matrix expansion**, with each combination evaluated on its own, and declared shapes for matrices computed at
  run time ([`matrixShapes`](/docs/configuration#matrix-shapes)).
- **53 [rules](/docs/rules)** (`FP1xx`–`FP9xx`) with stable codes, a page each and `flowpact explain`.
- **[Overrides](/docs/configuration#overrides)** with a mandatory reason, an optional expiry date and owner. Expired,
  unused and soon-expiring overrides are reported (`FP901`–`FP903`).
- **[Plugins](/docs/custom-rules):** an organization's own rules, loaded from the config.

### Where it runs

- **CLI:** `lint`, `check`, `impact`, `generate`, `remotes`, `graph` (tree, Mermaid, DOT, JSON), `trace`, `explain`,
  `rules` and `lsp`. Pretty, JSON, Markdown and SARIF output.
- **[GitHub Action](/docs/action):** a job summary, pull request annotations, SARIF, and the regenerated contracts as an
  artifact.
- **[Language server](/docs/editors)** (`flowpact lsp`): findings as you type across files, hover traces, go to
  definition across workflow calls, and references. Calls into other repositories are described from the remote
  interfaces lockfile, and go to definition opens their cached sources.
  [Quick fixes](/docs/editors#quick-fixes) rename a misspelled name, add a missing input, secret or matrix key, remove
  an unused input, regenerate the contracts, and accept a finding with an override.
- **[VS Code extension](/docs/editors#vs-code)** on the Visual Studio Marketplace and Open VSX, with the language server
  bundled.
- **[API](/docs/api)**: every command as a function, for scripts and your own actions.
- Published JSON Schemas for the config file, the contracts and the reports.

### Shared workflows

- **[Contracts](/docs/contracts):** `flowpact generate` writes a lockfile per published workflow and action, and
  `flowpact check` reports missing, outdated, orphaned and invalid contracts and breaking interface changes
  (`FP801`–`FP805`), with a patch for anyone who cannot run the CLI.
- **[Impact mode](/docs/impact-mode):** the release a pull request declares (its Conventional Commits title, labels or
  release version) is checked against what its changes require, including the check names that branch protection
  depends on (`FP810`–`FP814`).
- **[Remote interfaces](/docs/remote-interfaces):** `flowpact remotes update` records the interfaces of the workflows
  and actions you call in other repositories, and calls into them are checked like local ones. On GitHub Enterprise
  Server and GHE.com too, with an opt-in look on github.com as GitHub Connect does. GitHub's own
  [`actions.lock`](/docs/remote-interfaces#githubs-actionslock) decides which commit is read.
- **[Version changes, graded against your calls](/docs/remote-interfaces#when-a-version-changes):** when a reference
  moves to another version, each of your calls is graded as broken, unchecked or still fitting: in a scheduled drift
  check, and on the pull request that moves it.

## Next: the rest of the editor

- **Rename** an input, secret or output across its declaration, its callers and its reads.
- **Contract files:** hover, and go to definition to what each entry records.
- **Navigation** for `env` set on a step or in a composite action, step outcomes and step ids.
- **Completion** of the inputs and secrets of calls into other repositories, from the lockfile, without a network.
