## Shipped

- **Data-flow engine:** workflows and local composite actions, nested reusable workflows, same-repository references.
- **Exact matrix expansion** and per-combination evaluation; declared shapes for runtime-computed matrices
  (`matrixShapes`).
- **53 rules** (`FP1xx`–`FP9xx`) with stable codes, docs pages and `flowpact explain`.
- **[Contracts](/docs/contracts):** `flowpact generate` writes a deterministic lockfile per workflow and local action;
  `flowpact check` reports missing, outdated, orphaned and invalid contracts and breaking interface changes
  (`FP801`–`FP805`), with a `git apply`-able patch for anyone who cannot run the CLI.
- **[Overrides](/docs/configuration#overrides)** with a mandatory reason, an optional expiry date and owner; expired,
  unused and soon-expiring overrides are reported (`FP901`–`FP903`).
- **[GitHub Action](/docs/action):** job summary, pull request annotations, SARIF and the regenerated contracts as an
  artifact.
- **CLI:** `lint`, `check`, `impact`, `generate`, `remotes update`, `graph` (tree, Mermaid, DOT, JSON), `trace`,
  `explain`, `rules`, `lsp`; pretty, JSON, Markdown and SARIF output; debug logging.
- **[Plugins](/docs/custom-rules):** organization-specific rules loaded from the config.
- **[Impact mode](/docs/impact-mode):** for publishers of reusable workflows and actions — the release impact a pull
  request declares (Conventional Commits title, labels or release version) is checked against what its changes
  require, including the check names consumers' branch protection depends on (`FP810`–`FP814`).
- **[Remote interfaces](/docs/remote-interfaces):** `flowpact remotes update` records the interfaces of the reusable
  workflows and actions you call from other repositories in a committed lockfile, and calls into them are checked like
  local ones (`FP101`–`FP103`, `FP201`, `FP202`, `FP205`, `FP301`); `FP611` and `FP612` report an unusable or outdated
  lockfile. On GitHub Enterprise Server and GHE.com, with an opt-in look on github.com as GitHub Connect does.
- **[Language server](/docs/editors)** (`flowpact lsp`): diagnostics as you type across files, hover traces, go to
  definition across workflow calls, and references.
- **[VS Code extension](/docs/editors#vs-code)** on the Visual Studio Marketplace and Open VSX, with the language server
  bundled.
- Config file, contracts and reports with published JSON Schemas.

## Next: quick fixes in the editor

Add a missing input, remove an unused one, add the missing matrix key, regenerate contracts, or **add an override**
with a reason prompt, from the editor.

## Then: version changes, graded against your calls

When a remote reusable workflow or action moves to another version (a Renovate or Dependabot pull request, or a moving
tag such as `@v4` that now points elsewhere), flowpact will compare the two interfaces and say, for each of your calls,
whether it breaks, still fits, or cannot be fully checked: on a schedule, and on the pull request that changes the
version.
